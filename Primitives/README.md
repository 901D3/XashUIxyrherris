# _**Primitives/**_

_**Primitives/**_ defines fundamental constants, macros, structs and definitions that can be used across any project without any dependencies.

_**Primitives/**_ may contain:
- POD structs/classes
- Enums
- Macros
- Constants
- Simple typedefs

_**Primitives/**_ must not contain:
- Helper functions
- Algorithms
- engine logics
- platform specific codes
